1. סיכום מנהלים
================================================================================
Holikar היא אפליקציית Web (SPA) בעברית RTL לביצוע בדיקות חדרים במלון.
נתוני הבדיקות נשמרים בדפדפן (IndexedDB / Dexie). אין שרת מסד נתונים לבדיקות החדרים.

נוסף מנגנון Admin נפרד לסגירה/פתיחה גלובלית של המערכת (Maintenance Lock):
זה נעילה בתוך האפליקציה, לא כיבוי של Vercel. האתר נשאר באוויר, ומסך Admin
נגיש גם כשהמערכת "סגורה" למשתמשים רגילים.

הממשק מותאם מטלפון צר (כ-320px) עד מסך מחשב רחב. בטלפון: תפריט תחתון.
במחשב (מ-1024px): Sidebar.

5. מנגנון Admin (Maintenance Lock)
================================================================================
התחברות:
  האימות בצד שרת בלבד. שם המשתמש והסיסמה לא שמורים ב-Frontend ולא ב-GitHub.
  הסיסמה נשמרת כ-Hash (scrypt) בקובץ .env המקומי (gitignored).
  שדות Username / Password במסך ריקים כברירת מחדל. אין value לסיסמה ב-HTML.

  משתני סביבה:
    HOLIKAR_ADMIN_USER
    HOLIKAR_ADMIN_PASSWORD_HASH
    HOLIKAR_SESSION_SECRET
    UPSTASH_REDIS_REST_URL      (לייצור — נעילה גלובלית)
    UPSTASH_REDIS_REST_TOKEN

  Session: Cookie בשם holikar_admin_session, httpOnly, SameSite=Lax, כ-8 שעות.
  Rate limit: 8 ניסיונות / 15 דקות לפי IP.
  Logout קיים במסך Admin.

API:
  GET  /api/system-status     ציבורי — מחזיר רק { locked }
  POST /api/admin/login
  POST /api/admin/logout
  GET  /api/admin/me
  POST /api/admin/lock        דורש session

אחסון מצב נעילה:
  מקומית: קובץ data/system-lock.json (לא עולה ל-GitHub)
  Vercel: Redis (Upstash / Vercel KV) — חובה לנעילה אחידה בין טלפונים
  בלי Redis בייצור: זיכרון שרת בודד בלבד (לא גלובלי)

חשוב ל-Vercel: אחרי שינוי Hash/.env מקומי יש להעתיק את המשתנים ל-Vercel
ואז Redeploy. בלי זה הכניסה תעבוד רק במחשב המקומי.
