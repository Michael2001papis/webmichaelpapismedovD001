1. מה זו Holikar ולמה היא קיימת
--------------------------------------------------------------------------------

Holikar מחליפה את בניית הטבלאות מחדש בכל פעם ב-Word וב-Excel.

הרעיון המרכזי:
כתוב בשפה חופשית מה החדרים ומה צריך לבדוק — תוך שניות מתקבלת טבלת עבודה
מוכנה. מסמנים סטטוסים מהטלפון תוך כדי הליכה בין החדרים, שומרים הכל בארכיון,
ומייצאים PDF או Excel למנהל.

המערכת בעברית מלאה, מותאמת לטלפון ולמחשב.


--------------------------------------------------------------------------------
2. איך פותחים את האפליקציה
--------------------------------------------------------------------------------

אחרי פרסום (Vercel):
- פותחים בדפדפן את כתובת האתר החי ש-Vercel נותן (או דומיין מותאם, אם הוגדר).
- אפשר לפתוח מהמחשב ומהטלפון, בלי npm run dev.
- מומלץ להוסיף למסך הבית בטלפון, כדי שתתנהג יותר כמו אפליקציה.

פיתוח מקומי במחשב:
1. פותחים את תיקיית הפרויקט.
2. בטרמינל מריצים:

   npm run dev

3. נכנסים בדפדפן ל:

   http://localhost:5173

בטלפון (אותה רשת Wi-Fi של המחשב, רק בזמן פיתוח מקומי):
- בטרמינל מופיעה גם כתובת Network, למשל:
  http://10.100.102.10:5173
- פותחים ב-Chrome או Safari.

חשוב לפיתוח מקומי:
המחשב חייב להישאר דולק עם npm run dev רץ. בלי זה כתובת localhost לא תיפתח.
אחרי הפרסום ב-Vercel אין צורך בזה לשימוש יומיומי.

כותבים בשפה חופשית, למשל:

  אני צריך לבדוק בחדרים 201, 217, 241, 249 ו-253:
  שיפוע מזגן, ניקוז מקלחון, דלת כניסה וכורסאות.

  • מספרי החדרים

אם מעדיפים בלי טקסט חופשי:

8. עבודה לפי חדר (טלפון / שטח)
--------------------------------------------------------------------------------

זה המסך שמשתמשים בו כשמסתובבים בין החדרים.

1. מחפשים מספר חדר בתיבת החיפוש, או בוחרים מהרשימה לפי קומה.
2. צבעי תגיות החדרים:
     כהה      — החדר הנוכחי
     ירוק     — כל הבדיקות בחדר כבר סומנו
     אדום     — יש ליקוי או דבר שדורש מעקב
     רגיל     — עדיין חסר מידע
3. בחדר עצמו מסמנים לכל בדיקה:

     ✓ תקין
     ✕ לא תקין
     ? מידע חסר

   וגם (כפתורים קטנים יותר):
     לא רלוונטי
     דורש מעקב
     טופל

4. אם סומנים "לא תקין" או "דורש מעקב" — נפתחת תיבת הערה.
   לדוגמה:

     חדר 241
     שיפוע מקלחון — לא תקין
     הערה: המים נשארים באזור הכניסה ולא מתנקזים בצורה תקינה.

5. קיצורי דרך:
     הכל תקין והמשך    — מסמן את כל הבדיקות בחדר כתקינות ועובר לחדר הבא
     דלג לחדר חסר      — קופץ לחדר הבא שעדיין יש בו מידע חסר
     הקודם / הבא       — מעבר בין חדרים לפי הסדר

ההערות נשמרות אוטומטית תוך כדי הקלדה.

--------------------------------------------------------------------------------
17. שמירת מידע — מה חשוב לדעת
--------------------------------------------------------------------------------

הכל נשמר אוטומטית בדפדפן (IndexedDB). אין כפתור "שמור".

אבל:
  • זה לא בענן.
  • מחשב וטלפון הם שני ארכיונים נפרדים. מה שנעשה במחשב לא יופיע בטלפון,
    ולהפך, אלא אם מייצאים/משחזרים גיבוי או עובדים דרך אותו דפדפן באותו מכשיר.
  • ניקוי היסטוריה / נתוני אתר בדפדפן יכול למחוק את כל הארכיון.
  • Excel, PDF וקובץ הגיבוי הם הדרך הבטוחה לשמור עותק.

אין כרגע התחברות משתמשים, ואין שרת משותף לצוות.
אם כמה אנשים צריכים לראות את אותן בדיקות — בינתיים מייצאים Excel/PDF
או מעבירים קובץ גיבוי.

18. זרימת עבודה מומלצת ליום רגיל
--------------------------------------------------------------------------------

בבוקר / כשמקבלים משימה:
  1. פותחים את Holikar.
  2. כותבים מה ביקשו לבדוק, או פותחים תבנית מוכנה.

  4. יוצרים טבלת עבודה.

בשטח, בטלפון:
  1. פותחים את הבדיקה.
  2. עובדים במצב "לפי חדר".
  3. נכנסים לחדר, מסמנים, כותבים הערה אם צריך.
  4. "הכל תקין והמשך" כשהחדר בסדר.
  5. בסוף עוברים על "רק ליקויים" כדי לוודא שלא פספסו כלום.

בסיום:
  1. מייצאים PDF למנהל.
  2. מייצאים Excel אם צריך לעבוד על הנתונים.
  3. בהגדרות — הורדת גיבוי.


--------------------------------------------------------------------------------
19. פתרון בעיות נפוצות
--------------------------------------------------------------------------------

הכתובת לא נפתחת
  בודקים ש-npm run dev רץ, ושנכנסים ל-http://localhost:5173

הטלפון לא מוצא את האתר
  המחשב והטלפון חייבים להיות על אותו Wi-Fi.
  משתמשים בכתובת Network שמופיעה בטרמינל, לא ב-localhost.

המערכת לא זיהתה חדרים או בדיקות
  לוחצים "זהה חדרים ובדיקות", או מתקנים ידנית בטופס שמתחת.
  אפשר תמיד להוסיף חדרים ועמודות ביד.

חסרה עמודה
  במסך הבדיקה פותחים "עמודות בדיקה" ומוסיפים.

נמחקו כל הבדיקות
  אם יש קובץ גיבוי JSON — בהגדרות, "שחזר מגיבוי".
  אם אין גיבוי — הנתונים מהדפדפן אבדו. לכן חשוב לגבות.
